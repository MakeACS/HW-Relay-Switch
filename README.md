# Relay Switch

The Relay Switch provides 2 sets of double-throw dry contacts, allowing open-ended integration with a wide variety of control loops. Common examples include interlocks, e-stops, door magnets, and more.

For larger integrations into an electrical cabinet, consider the [DIN Relay Switch](https://github.com/MakeACS/HW-DIN-Relay-Switch), which provides the relay in an easier-to-mount and easier-to-wire enclosure, and includes a power supply internally.
